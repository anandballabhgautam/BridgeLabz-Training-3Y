Responsive CSS Cheat Sheet

Filters

Visual effects on elements. Example: filter: grayscale(100%);

Media Queries

Apply styles by screen size. Example: @media (max-width: 600px) { ... }

Responsive Design

Layouts that adapt to any device using fluid grids, flexible images and breakpoints.

Typography

Scalable text. Example: font-size: clamp(1rem, 2vw, 1.5rem);

Flexbox

One-dimensional layout. Example: display: flex;

Grid

Two-dimensional layout. Example: grid-template-columns: repeat(3, 1fr);
