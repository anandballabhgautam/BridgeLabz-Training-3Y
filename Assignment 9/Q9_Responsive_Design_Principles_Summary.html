Responsive Design Principles

Hover over a box.

Fluid Layouts

Use percentages and flexible units so layouts stretch and shrink with the screen.

.container {
  width: 90%;
  max-width: 1100px;
}

Flexible Media

Images and videos scale inside their containers instead of overflowing.

img {
  max-width: 100%;
  height: auto;
}

Breakpoints

Media queries change the layout at specific screen widths.

@media (max-width: 600px) {
  .grid { grid-template-columns: 1fr; }
}
