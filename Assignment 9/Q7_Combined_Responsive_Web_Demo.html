What is Responsive Design?

Responsive design makes a website look good on every screen. It uses flexible layouts, scalable images and media queries so the same page works on phones, tablets and desktops.

Cheat Sheet Preview

  • Filters: filter: blur(2px)
  • Media Query: @media (max-width: 700px)
  • Grid: repeat(auto-fit, minmax(200px, 1fr))
