# Assignment 6 — HTML & CSS (Flexbox and Grid)

This folder contains all 10 assignment questions. Each question has its own folder containing:
- `index.html` — semantic HTML structure
- `style.css` — responsive CSS styling

## Run the assignment
1. Extract `Assignment_6.zip`.
2. Open the `Assignment_6` folder in VS Code.
3. Open any question folder.
4. Open `index.html` in your browser or use Live Server.

## Notes
- No JavaScript is used.
- No external CSS frameworks are used.
- Layouts use Flexbox and/or CSS Grid.
- Remote Unsplash images require an internet connection.
- Replace sample names and contact details with your own before submission.
