box-sizing: content-box vs border-box

Both boxes have the same CSS: width 220px, padding 25px and border 5px.

Default (content-box)

The width applies only to the content. Padding and border are added on top.

Total = 220 + 50 + 10 = 280px

border-box

The width includes the content, padding and border, so the box stays the size you set.

Total = 220px
